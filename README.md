# OttoXC Releases

Public release artifacts for OttoXC's alpha distribution channel
(`ottoxc-launcher`/`ottoxc-tray` payload tarballs).

Source code lives in the private `ottoxc/xc-platform` repository; this
repo exists only to host publicly-downloadable build artifacts so the
launcher app can fetch updates without requiring authentication.

See `docs/plans/alpha-launcher-payload-hosting.md` in `xc-platform` for
the full packaging/publishing design.
